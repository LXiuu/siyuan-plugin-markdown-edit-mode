# Markdown源码模式

将当前文档临时切换为 Markdown 源码编辑状态的思源笔记插件。

当前版本仅支持桌面端：`desktop`、`browser-desktop`、`desktop-window`。

插件会在当前文档左下角提供一个“源码模式”按钮。点击后，当前文档会进入一个全屏覆盖式的 Markdown 编辑器，你可以像编辑普通 Markdown 文件一样直接修改源码；退出源码模式后，文档会回到思源的正常渲染视图。

## 使用前注意

- **源码模式会把 Markdown 写回思源并重新解析为块结构，不是无损的块源码编辑。**
- **数据库块、超级块、嵌入块、块属性 / 自定义属性、子块 ID、块引用、PDF 标注和复杂 HTML 等内容可能无法完整保留。**
- **编辑会自动实时写回当前文档；如果只是查看源码，请避免修改内容。**
- **重要或复杂文档建议先备份，实时更新失败时请先复制当前源码再处理异常。**

## 功能简介

- 在当前文档左下角显示“源码模式”入口，贴近思源状态栏风格。
- 使用 CodeMirror 6 提供 Markdown 源码编辑、语法高亮、行号、折行、括号匹配和编辑历史。
- 进入源码模式时，优先定位到当前光标附近内容，并尽量保持原来的阅读位置。
- 编辑内容后会自动延迟实时更新，并在右下角显示实时更新状态。
- 退出源码模式时会刷新当前编辑器，让正文渲染和大纲尽快同步。
- 支持粘贴 Markdown 时自动清理外层 Markdown 代码围栏，并处理常见缩进。
- 自动过滤思源 Markdown 导出时可能附带的 `title`、`date`、`lastmod` 元数据。
- 自动移除导出内容开头与文档名重复的一级标题，避免写回后正文多出重复标题。
- 不直接读写 `workspace/data` 下的文件，读写均通过思源内核 API 完成。

## 使用说明

1. 打开一个普通文档。
2. 点击左下角的“源码模式”按钮，进入 Markdown 源码编辑状态。
3. 在源码编辑器中修改内容。
4. 修改后等待右下角出现“实时更新成功 HH:MM:SS”，或直接点击左下角“退出模式”保存并返回渲染视图。

源码模式支持以下快捷键：

| 快捷键 | 作用 |
| --- | --- |
| 双击 `Ctrl` | 进入源码模式；源码模式下保存并退出 |
| `Ctrl + S` | 源码模式下保存并退出 |
| `Esc` | 源码模式下保存并退出 |
| `Tab` | 在源码编辑器中缩进 |

右下角状态说明：

| 状态 | 含义 |
| --- | --- |
| `实时更新已启用` | 已进入源码模式，等待编辑 |
| `正在实时更新...` | 正在将 Markdown 写回当前文档 |
| `实时更新成功 HH:MM:SS` | 本次修改已写回 |
| `实时更新失败 HH:MM:SS` | 本次写回失败，建议先不要关闭源码模式 |
| `当前处于只读模式，无法实时更新` | 当前环境不允许写入 |

## 版本更新说明

### v0.1.5

- 避免文档切换时使用过期的编辑器上下文。
- 切换文档时取消待执行的刷新和光标恢复任务。
- 压缩预览图体积，保持分辨率不变。

### v0.1.4

- 优化分屏场景下的源码模式入口，按钮会跟随当前正在编辑的文档区域显示。
- 修复上下分屏、左右分屏中按钮缺失、位置偏移和与正文重叠的问题。
- 调整源码模式和退出按钮样式，使其更贴近思源底栏风格。
- 优化源码编辑页宽度，窄分屏下仍保持较舒适的正文显示区域。

### v0.1.3

- 前置并加粗使用前注意，精简风险说明。
- 后端兼容声明调整为 `all`。

### v0.1.2

- 新增源码模式只读状态动态同步，覆盖思源编辑器只读设置、发布模式和已禁用的 Protyle 实例。
- 只读上下文下源码编辑器会进入不可编辑状态，并阻止粘贴分发绕过只读限制。
- 强化插件禁用、重新加载和更新时的资源清理，释放待执行的光标恢复观察器、定时器和动画帧。
- 文档标签页销毁或重新打开后，退出源码模式不再调用已过期的编辑器刷新句柄。
- 验证声明的桌面前端 `desktop`、`browser-desktop`、`desktop-window` 下 UI 显示正常。

### v0.1.1

- 移除插件清单中的 `all` 前端声明，避免移动端同步安装后加载桌面源码编辑器。
- 为源码模式按钮补充移动触摸事件拦截，避免触摸退出按钮时优先唤起软键盘。

### v0.1.0

- 新增当前文档 Markdown 源码编辑模式。
- 新增左下角“源码模式 / 退出模式”浮动按钮。

- 新增编辑后延迟实时更新，并显示实时更新状态。
- 新增双击 `Ctrl`、`Ctrl + S`、`Esc` 快捷键。
- 新增进入源码模式时的光标定位和退出后的光标恢复。
- 新增粘贴 Markdown 时的外层代码围栏清理和缩进整理。
- 新增思源导出元数据和重复文档标题清理。
- 新增保存后刷新当前编辑器，提升渲染视图同步速度。
