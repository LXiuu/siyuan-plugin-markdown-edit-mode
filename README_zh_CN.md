# Markdown源码模式

将当前文档临时切换为 Markdown 源码编辑状态的思源笔记插件。

当前版本支持思源桌面端，不支持手机和平板。

插件会在当前文档左下角提供一个“源码模式”按钮。点击后，你可以像编辑普通 Markdown 文件一样修改当前文档；退出源码模式后，文档会回到思源的正常编辑界面。

## 编辑规则

- 普通 Markdown 内容可以直接修改，包括文字、标题、代码块、公式、分隔线、HTML、列表、引述和表格。
- 暂时无法安全修改的思源专有内容会显示为锁定卡片，插件不会改动它们。
- 如果一次修改可能破坏原有内容或排版结构，插件会停止保存并给出提示。
- 修改会在约 1 秒后自动保存。
- 如果保存失败，可以放弃尚未保存的修改并正常退出源码模式。

## 功能简介

- 在文档左下角提供“源码模式”按钮。
- 提供更清晰的 Markdown 高亮、行号、自动折行、括号匹配和撤销记录。
- 普通内容可以像 Markdown 文件一样连续编辑，不能安全修改的内容会清楚标记并锁定。
- 自动保存修改，必要时保留恢复草稿，并在右下角显示保存状态。
- 进入和退出源码模式时，尽量保持原来的阅读位置。
- 退出后自动刷新正文和大纲。

## 使用说明

1. 打开一个普通文档。
2. 点击左下角的“源码模式”按钮，进入 Markdown 源码编辑状态。
3. 在源码编辑器中修改内容。
4. 等待右下角显示保存成功，或点击左下角“退出模式”保存并返回正常编辑界面。

源码模式支持以下快捷键：

| 快捷键 | 作用 |
| --- | --- |
| 双击 `Ctrl` | 进入源码模式；源码模式下保存并退出 |
| `Ctrl + S` | 源码模式下保存并退出 |
| `Esc` | 源码模式下保存并退出 |
| `Tab` | 在源码编辑器中缩进 |

右下角状态说明：

| 状态 | 含义 |
| --- | --- |
| `内容块安全更新 · 可编辑 N · 已保护 M` | 显示当前可以修改和已锁定的内容数量 |
| `等待更新 · 受保护内容块不会被改写` | 修改即将自动保存 |
| `正在更新 N 个内容块...` | 正在保存修改 |
| `已更新 N 个内容块 HH:MM:SS` | 修改已经保存成功 |
| `<块类型> 当前受保护，不能直接修改` | 这部分内容暂时不能安全修改 |
| `当前处于只读模式，无法实时更新` | 当前环境不允许写入 |
